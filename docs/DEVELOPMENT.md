# Development documentation

## KW-SERVICE

asd

### Java

The project uses _Java_ with version of 21.0.7 _Temurin_ flavor. If you have _sdkman_ installed, you can enable the correct _Java_ version by running command `sdk env install` in the directory where `.sdkmanrc` file is located.

## KW-WEB

asd

### Node

The web project uses _Node_ with version of _v24.14.1_ (current lts). If you have **nvm** installed, you can enable the correct _Node_ version by running command `nvm install` in the directory where `.nvmrc` file is located.
