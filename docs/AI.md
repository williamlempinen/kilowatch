# AI Usage

## Tools used

GitHub Copilot and Github Copilot Chat (editor chat panel)

Claude Code for discussion of more broader topics, such design decisions

## How AI was used

AI was used to support the development and to provide more development speed and learnings. Some design decision were
first asked from Claude Code before I made the final decision and started to work with initial implementation myself.
After I had made the initial scaffolding of the project, I used Copilot to help with the implementation of the features
and to provide suggestions for code completion.

Some smaller details were initially first made by Github Copilot but then verified by myself. For example, some method
or function were first created by AI and then later modified and verified by myself.

### Examples of Usage

#### Writing frontend tests

For frontend tests, AI was tasked to write all the tests cases in the purpose of ease and development speed. Each test
case was later verified that they are actually testing the correct functionality.

Reason for this was that I didn't have any experience of _Playwright_ or _Vitest_ prior to this exercise.

### Debugging failing tests

Copilot was used to investigate what my changes broke tests cases
